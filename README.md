# Introduction to Artificial Intelligence for Computer Vision Using PyTorch and TensorFlow  
**Fo Guang University — January 9, 2026**

This GitHub repository contains datasets and source code (Google Colab notebooks) used in the **Artificial Intelligence for Computer Vision** session held at **Fo Guang University** on **January 9, 2026**.

The materials are intended for hands-on learning and demonstrations of computer vision applications using **PyTorch** and **TensorFlow**, including face classification and semantic segmentation.
This training focuses on the introduction to AI for computer vision applications using Python programming for a beginner-level audience. Participants will learn the fundamentals of deep learning for computer vision and explore its practical applications. The session begins with an introduction to basic Python programming, followed by hands-on use of PyTorch and TensorFlow as the primary libraries for AI development. Key topics include dataset handling, model development and training, and model evaluation and accuracy assessment. The training includes two hands-on mini projects focusing on image classification and semantic segmentation tasks.
